**HiveMind 0.1.0.7** — separate player edition with compatible bot updates for **Minecraft 26.3 / Fabric**.

- **Bot accounts:** keep using **hivemind-0.1.0.7.jar**. The bot filename pattern and existing public update-manifest URL are unchanged. Existing saved roles survive updates, including manual mode on the older shared client.
- **Your player account:** install **hivemind-player-0.1.0.7.jar**. It starts in manual sharing mode and is locked there regardless of saved bot settings. Local and remote commands cannot enable bot automation. It shares position, terrain and loaded entity observations without displaying HiveMind ESP overlays or controlling your character.
- Both editions support first-join automatic-update consent, **#update**, and permitted controller update controls. The player edition uses its own public update manifest; the standard edition keeps the existing one. The downloader and post-exit installer validate edition metadata and reject cross-edition replacements. Legacy standard installations can upgrade normally.
- Both JARs come from the same Fabric build and carry the same mod ID, dependencies and network protocol 7. Install **one edition per Minecraft instance**, removing the previous HiveMind mod. The standalone controller remains separate.

Existing bots can use **#update install**, then close and relaunch Minecraft. To move your personal instance to the locked player edition, replace its old mod with the player JAR once; later player updates are automatic after consent. Keep the controller's data directory when replacing its application. Role, packaging, manifest, installer, controller and Fabric checks cover this release; live multiplayer behavior still needs gameplay validation.
