**HiveMind 0.1.0.9** — player-side bot base and storage commands for **Minecraft 26.3 / Fabric**.

- **#bots list** shows fresh connected autonomous bot accounts. Use **#bots all ...**, a bot name or an exact UUID to address the team or one bot. Manual player clients, stale telemetry and offline bots cannot be selected.
- **#bots all base set [radius]** assigns YOUR current location to the bots, rather than each receiving bot's feet. Explicit dimensions/coordinates are supported. Base status, scan, clear and resupply commands work too.
- Look at a supported chest/barrel and use **#bots all chest add supplies**, or omit the rule to keep the existing/default rule. Normal, trapped and copper variants are supported. **chest remove** removes that location independently of each bot's local storage ID. **chest list [page]** returns storage lists. Explicit endpoint coordinates are also supported.
- Commands use the existing authenticated host-validated network control route. Individual bot confirmations/failures appear in the issuing client's chat. Command IDs remain deduplicated and do not replay to offline bots. Bots reject location edits during active supply trips; loaded containers are validated immediately, and unloaded endpoints are checked on arrival.
- The player JAR remains locked to manual sharing. Only the new outbound **#bots** command is allowed locally; it cannot enable local movement, combat or inventory automation, and cannot be remotely invoked to fan out more commands.

Update both the player client and bots with **#update install**, then restart Minecraft. Standard **hivemind-0.1.0.9.jar** and separate **hivemind-player-0.1.0.9.jar** update channels are unchanged; protocol remains 7. The direct ESP-contact pursuit and landing fixes from 0.1.0.8 remain included. Automated policy, routing, packaging and Fabric checks cover the release; live multiplayer command/placement behavior still needs gameplay testing.
